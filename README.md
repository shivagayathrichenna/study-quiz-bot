# Study Quiz Bot 📚🤖

An automated Telegram study quiz bot built using **n8n**, **Groq API**, and **Arena.ai** frameworks. Designed to process study materials and generate interactive multiple-choice quizzes automatically.

👉 **[Try Study Quiz Bot on Telegram](https://t.me/notes_quiz_bot_username)**

## 🚀 Tech Stack & Architecture
* **Automation Platform**: n8n
* **LLM Engine**: Groq API
* **Evaluation / Framework**: Arena.ai
* **Interface**: Telegram Bot API

## 📁 Repository Contents
* `workflow.json` - Complete n8n workflow export
* `README.md` - Project documentation and setup guide

## ⚙️ Setup Instructions
1. Import `workflow.json` into your n8n instance.
2. Configure environment credentials for Groq API and Telegram Bot Token.
3. Activate the workflow and trigger via Telegram commands.
